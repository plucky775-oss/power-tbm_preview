설치와 오프라인 기능은 HTTPS 배포 주소 또는 `localhost`에서 작동합니다. 단순히 `index.html` 파일을 직접 여는 방식(`file://`)에서는 서비스워커가 등록되지 않습니다. 로컬 확인은 이 폴더에서 간단한 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

정적 사이트이므로 폴더 전체를 GitHub 저장소에 올린 뒤 Vercel에서 Framework Preset을 `Other`로 선택하고 Build Command 없이 배포할 수 있습니다.

## 휴대기기 설치와 오프라인 사용

- Android: Chrome에서 홈페이지를 연 뒤 메뉴의 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
- iPhone·iPad: Safari에서 홈페이지를 연 뒤 `공유` → `홈 화면에 추가`를 선택합니다.
- 설치 전 첫 접속은 인터넷이 연결된 상태에서 완료해야 화면·글꼴·내레이션·배경음·영상을 기기에 저장할 수 있습니다.
- 설치가 끝난 뒤에는 인터넷이 없어도 버튼 클릭 장면, 전체 자동 시연과 모든 소리, 골든룰스11 및 현장 배경영상이 재생됩니다.
- 앱을 새로 실행하면 우측 하단의 `소리로 재생` 또는 `무음으로 재생`을 한 번 눌러 바로 시작합니다.

## 주요 파일

- `index.html` — 한 페이지 시연 화면과 개발자 표기
- `styles.css` — PC·태블릿·모바일 반응형 레이아웃
- `app.js` — 자동 시연, 구간 전환, 음성·배경음 제어

- `pwa.js`, `sw.js` — 설치 등록과 화면·소리·영상 오프라인 저장
- `assets/screens/guide/` — 실제 앱 화면 이미지
- `assets/audio/` — 내레이션 및 배경음
- `assets/video/` — 시연용 영상과 포스터
- `assets/background/` — 구간별 현장 배경영상·포스터와 출처 정보
- `assets/brand/` — Power TBM 아이콘과 브랜드 이미지

## 운영 참고

- 브라우저 정책상 최초 접속 시 `소리로 재생`을 직접 선택해야 내레이션과 배경음이 재생됩니다.
- `무음으로 재생`을 선택하면 영상과 화면 시연만 진행되며, 상단 사운드 버튼으로 언제든 소리를 켤 수 있습니다.
- 골든룰스11 영상은 전체 사운드 ON/OFF와 관계없이 항상 무음으로 재생됩니다.
- 골든룰스11 영상은 실제 시연 구간에 필요한 7초 동작 장면만 사용해 설치 용량과 디코딩 부담을 줄였습니다.
- 현장도구 배경은 절연스틱 표준시공 영상의 4분 13초 이후 작업 장면을 원본과 동일한 1배속·30fps로 100초 동안 사용하며, 제목·설명 자막과 영상 로고는 확대 구도로 모두 제외했습니다.
- 응급의료 배경은 창원성산소방서 119 구급차 출동 영상으로 교체하고, 우측 상단 편집기 표시는 잘라낸 뒤 서명 구간 동안 움직임이 계속 이어지도록 100초 타임라인에 맞췄습니다.
- 마지막 멘트 배경은 `한국전력공사 TBM가이드`의 9분 5초부터 9분 11.37초까지를 정상 1배속·30fps로 사용하며, 글씨가 나타나기 직전 작업자 단체 화이팅 장면에서 재생을 멈추고 마지막 프레임을 유지합니다.
- 오프라인 미디어 구간 요청은 기기 메모리에서 재사용하고, 최초 오프라인 저장은 소규모 묶음으로 진행해 첫 실행 중 화면 끊김을 줄였습니다.
- 기존 설치본을 업데이트할 때는 온라인 상태에서 새 배포본을 한 번 연 뒤 앱을 완전히 닫았다가 다시 실행합니다.
- 화면 캡처를 교체할 때는 기존 파일명을 유지하면 코드 수정 없이 반영할 수 있습니다.
- 배경음 저작권 정보는 `assets/audio/BGM_CREDITS.txt`에서 확인할 수 있습니다.
- 배경영상 출처와 이용 조건은 `assets/background/ATTRIBUTION.md`에서 확인할 수 있습니다.

## v85 · 전체 음성 자막

- 하단 `자막 ON / OFF` 버튼으로 전체 내레이션 자막을 표시합니다. 기본 ON이며 브라우저에 선택을 저장합니다.
- 단어별 음성 시점에 맞춰 흰색 글씨가 노란색으로 바뀝니다. 음소거 중에도 표시되며 구간 이동·일시정지와 동기화됩니다.
- 최신 v84의 4컷 소개 음성과 원본 MP4 음성은 각각의 재생 시간에 맞춘 자막을 사용합니다. 음성 인식 기반 시간이므로 일부 발음에 미세한 차이가 있을 수 있습니다.
- 영상 자체에 포함된 글자는 자막 OFF로 사라지지 않습니다. 원본 미디어와 끝까지 재생하는 로직은 유지합니다.
- `subtitle-data.js`, `subtitles.js`, `subtitles.css`를 추가하고 PWA 캐시를 v85로 갱신했습니다.
- 확인: 기존 원본 영상 회귀검사, 오프라인 캐시·Range 응답 검사, Chromium의 ON/OFF 저장·음소거·소개/영상 자막 전환 및 반응형 표시. 실제 iPadOS Safari와 녹화 파일 출력은 별도 확인이 필요합니다.

## v86 · 말풍선과 기존 자막 효과 선택

- 우측 하단의 자막 표시 방식에서 `기존 자막 효과 / 말풍선 안내 / 자막 끄기`를 선택합니다.
- 기존 효과는 전체 대사와 흰색→노란색 강조를 그대로 유지합니다. 말풍선은 같은 음성 시점에 맞춘 짧은 안내를 화면 옆에 표시하고, 좁은 화면에서는 시연 화면 위에 배치합니다.
- 선택은 브라우저에 저장됩니다. 이전 ON/OFF 설정을 유지하며, 별도 선택이 없으면 기존 효과로 시작합니다.
- 기존 영상 및 음성, 단어별 타이밍 데이터는 변경하지 않았습니다.
- 확인: `node tests/verify-subtitle-modes.mjs`, `node tests/verify-original-video.mjs`, `node tests/verify-pwa.mjs` 통과. 이번 환경은 브라우저 실행 소켓 권한 및 권한 상승 정책 때문에 실제 화면 검증을 수행하지 못했습니다. iPad/휴대폰에서 말풍선 위치와 가림 여부는 확인이 필요합니다.


## v87 · 말풍선 전체 자막 교정

- 말풍선의 요약 문구를 제거하고 기존 전체 자막과 동일한 문구·시간 데이터를 사용합니다.
- 말풍선도 음성에 맞춰 문구가 차례로 바뀌며, 내용을 줄이거나 생략하지 않습니다.
- 선택 메뉴는 `기존 자막 효과 / 말풍선 자막 / 자막 끄기`입니다. 기존 하단의 흰색→노란색 강조와 선택 저장 기능은 유지합니다.
- 모든 구간의 말풍선 문구가 기존 자막과 일치하는지 검사했습니다. 브라우저 실행 권한 제한으로 실제 기기 화면 배치는 별도 확인이 필요합니다.
