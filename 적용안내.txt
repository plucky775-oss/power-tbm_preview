수동 적용 방법
1. ZIP을 압축 해제하고 먼저 manifest.json과 검증결과.txt를 확인합니다.
2. GitHub에서 해당 저장소 main의 최신 커밋이 기준 커밋과 같은지 확인합니다.
3. 저장소 루트에서 Add file → Upload files를 엽니다.
4. repo-files 폴더 안의 파일과 하위 폴더를 원래 경로 그대로 업로드합니다.
   repo-files라는 폴더 자체를 저장소에 추가하면 안 됩니다.
   적용안내.txt, 검증결과.txt, manifest.json도 저장소에 올리지 않습니다.
   대안: 로컬 저장소 루트에 repo-files 내용만 복사하고 17개 파일의 diff를 검토합니다.
5. 변경 목록이 manifest.json의 17개 경로와 일치하는지 확인한 후 커밋합니다.
   권장 메시지: Fix daily forecast pronunciation with full Jisoo sentence (v139)
6. 연결된 Vercel 자동 배포가 있다면 해당 커밋 배포가 성공한 뒤 소개앱을 확인합니다.
   배포 성공 전에는 운영앱 반영 완료로 판단하지 마세요.
7. 일반 화면과 TV 모드에서 기상정보를 재생하고 해당 문장 발음을 직접 들어보세요.
   설치형 앱은 현재 시연을 종료한 뒤 앱을 다시 열어 새 오프라인 캐시를 받으세요.
   sw.js에 v139-20261024-weather-sentence가 있고 새 음성이 재생되는지 확인합니다.
