Power TBM PC 녹화 버튼 v81 적용 방법

1. 압축 안의 코드 파일 8개를 현재 Power TBM 소개 홈페이지의 최상위 폴더에 복사합니다.
   같은 이름은 덮어쓰고 새 이름은 추가하세요. assets 폴더는 건드리지 않습니다.
   - 기존 교체: index.html, app.js, sw.js, styles.css, safety4cut.css, demo-hands-v80.css
   - 새로 추가: demo-recorder-v81.css, demo-recorder-v81.js
   손가락 크기 수정이 빠지지 않도록 현재 CSS도 함께 넣었습니다.

2. PC Chrome에서 사이트를 새로 열고 처음의 재생 모드를 선택합니다.
   상단 맨 오른쪽, 소리 버튼 다음에 작은 ‘녹화’ 버튼이 나옵니다.
   업데이트 직후 이전 화면이 보이면 열려 있는 해당 사이트 탭을 닫았다가 다시 열어 주세요.

3. 녹화 → 녹화 시작 → 이 Power TBM 탭 선택 → ‘탭 오디오 공유’ 켜기 → 공유.
   다른 창이나 전체 화면 대신 이 사이트의 탭을 선택하세요.
   현재 탭의 화면과 소리를 녹화하므로 시연 중 이 탭을 앞에 두고 소리를 켜 주세요.
   녹화가 시작되면 소리를 켜고 전체 시연을 처음부터 다시 재생합니다.

4. 상단 ‘중지’를 누르거나 전체 시연의 마지막까지 기다리세요.
   녹화가 끝나면 미리보기의 재생 버튼으로 화면과 소리를 확인한 뒤 ‘영상 저장’을 누릅니다.
   MP4를 지원하면 MP4, 그렇지 않으면 WebM으로 저장합니다.
   녹화 창을 닫아도 녹화 버튼을 다시 누르면 결과를 열 수 있습니다.
   파일을 저장하기 전에 사이트를 닫거나 새로고침하면 녹화 결과가 사라집니다.

검증
- 권한 취소/재시도, 소리 누락, 형식/마지막 데이터, 공유 종료/자동 종료, 캐시 검사 통과.
- 실제 PC의 공유 선택창, 화면 배치, 영상·음성 인코딩 및 다운로드는 미검증입니다.
  작업 환경의 미리보기 접속이 차단되어 실기기 검증을 하지 못했습니다.
  적용 후 먼저 짧은 녹화로 화면과 소리를 확인해 주세요.

이 압축은 현재 v79 영상·음원이 적용된 소개 홈페이지용 수정 파일입니다.
